---
title: "Install"
description: "Install the ACP adapter and point it at Codex CLI."
---

```sh
go install github.com/savid/acp-go-codex/cmd/acp-go-codex@latest
```

For embedded use:

```sh
go get github.com/savid/acp-go-codex
```

```go
err := codexacp.Serve(ctx, stdin, stdout,
    codexacp.WithExecutablePath("/usr/local/bin/codex"),
    codexacp.WithHome("/var/lib/my-host/codex"),
)
```

Use `-path` or `WithExecutablePath` to select a Codex executable. Use `-home`
or `WithHome` to set `CODEX_HOME` for launched Codex processes.

Login helpers delegate to Codex:

```sh
acp-go-codex login -device-auth
acp-go-codex logout
```

ACP logout is disabled unless the adapter is started with
`-codex-allow-account-logout` or `WithCodexAllowAccountLogout(true)`.
