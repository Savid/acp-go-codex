---
title: "Install"
description: "Install acp-go-codex and connect it to Codex CLI."
---

```sh
go install github.com/savid/acp-go-codex/cmd/acp-go-codex@latest
```

For embedded use:

```sh
go get github.com/savid/acp-go-codex
```

Codex CLI `0.144.1` or newer must be available through the configured selector.
Standalone mode resolves it in the current environment. Managed hosts configure
a selector they can pin and launch through `HostAuthority`.
