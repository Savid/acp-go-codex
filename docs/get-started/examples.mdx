Examples live under `examples/` and exercise the same public ACP surface that a
host uses.

## Minimal client

```bash
go run ./examples/minimal-client "Reply with hello from ACP"
```

The minimal client launches `acp-go-codex`, initializes ACP, creates a session,
sends one prompt, prints streamed updates, and closes the session.

## Interactive chat

```bash
go run ./examples/interactive-chat
```

The interactive client keeps a session open for repeated turns. It is useful
for checking prompt streaming, tool updates, cancellation, permission prompts,
elicitation callbacks, and usage reporting.

## Resume from file

```bash
go run ./examples/resume-from-file ./rollout.jsonl
```

The resume example imports Codex rollout JSONL through the
[`_codex/session/import*`](/docs/reference/session-import) extension surface and
then calls `session/load` to replay the restored timeline.

<Tip>
  Integration tests under `integration/` use the same examples and public
  methods as smoke coverage for a local Codex CLI.
</Tip>
