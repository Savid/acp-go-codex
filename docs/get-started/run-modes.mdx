## Standalone

With no isolation flag, the command launches Codex as its current identity.
It reports non-authoritative `shared_identity` on every platform where native
launch and writable-home locking are supported, including Windows. It publishes
no descendant inventory and makes no whole-tree quiescence claim. Add
`-process-isolation-config=/absolute/path/process-isolation.json` on Linux for
the explicit hardened identity, environment, ownership, and containment
contract documented in the [CLI reference](/docs/reference/cli).

```sh
acp-go-codex -process-isolation-config /etc/acp-go/codex-isolation.json -path /usr/local/bin/codex -home /var/lib/acp-go-codex -model gpt-5.5
```

The command speaks ACP JSON-RPC over stdin/stdout: stdout carries ACP JSON-RPC
only; diagnostics go to stderr (and `-debug` when present).

| Flag | Purpose |
| --- | --- |
| `-path` | Codex CLI executable path. |
| `-home` | `CODEX_HOME` for launched Codex processes; an explicit value must equal policy `HOME`. |
| `-scratch-dir` | Parent directory for ephemeral runtime generations. |
| `-process-isolation-config` | Optional explicit Linux child identity and closed environment policy. |
| `-model` | Default model preference for new sessions. |
| `-debug` | Write adapter diagnostics to stderr. |
| `-version` | Print adapter version and exit. |
| `-codex-allow-account-logout` | Permit ACP logout to mutate adapter-owned Codex auth. |

## Login helpers

```sh
acp-go-codex login -path /usr/local/bin/codex -home /var/lib/acp-go-codex -codex-device-auth
acp-go-codex logout -path /usr/local/bin/codex -home /var/lib/acp-go-codex
```

## Embedded Go

```go
err := codexacp.Serve(ctx, stdin, stdout,
	codexacp.WithExecutablePath("/usr/local/bin/codex"),
	codexacp.WithHome("/tmp/codex-home"),
	codexacp.WithDefaultModel("gpt-5.5"),
)
```

Embedded mode exposes the same ACP surface as the standalone binary.
Append `WithProcessIsolation(...)` only when the host explicitly selects the
hardened policy; an invalid explicit policy fails before native spawn and is
never retried in ordinary mode.
On Darwin, append `WithDarwinBestEffortContainment()` only when the operator
accepts that `setsid` descendants may escape and numeric PGID reuse can cause
collateral signalling.
