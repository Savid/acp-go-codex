---
title: "Run modes"
description: "Run acp-go-codex as a stdio process or embedded Go agent."
---

## Standalone

```sh
acp-go-codex -path codex -home /absolute/codex-home -model gpt-5.5
```

Standalone mode runs native work as the current user and speaks ACP over
stdin/stdout.

## Embedded

```go
err := codexacp.Serve(ctx, input, output,
	codexacp.WithExecutablePath("host-pinned-codex"),
	codexacp.WithHostAuthority(authority),
)
```

Omit `WithHostAuthority` for ordinary same-user behavior. Supply it when the
embedding host owns native leases and prepared-tree transitions.
