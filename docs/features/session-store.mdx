---
title: "Session Store"
description: "Durable Codex rollout JSONL storage."
---

`SessionStore` lets a host mirror Codex rollout rows and later load or resume a
session when local Codex thread state is absent.

```go
const SessionStoreMainSubpath = ""
const SessionStoreFormat = "codex-rollout-jsonl-v1"

type SessionKey struct {
    SessionID string
    Subpath   string
}
```

The store API is:

```go
type SessionStore interface {
    Append(context.Context, SessionKey, []SessionStoreEntry) error
    Load(context.Context, SessionKey) ([]SessionStoreEntry, error)
    Replace(context.Context, SessionKey, []SessionStoreReplacement) error
    Delete(context.Context, SessionKey) error
    ListSessions(context.Context) ([]SessionSummary, error)
    ListSubkeys(context.Context, SessionKey) ([]string, error)
}
```

`Replace` writes one complete committed generation for a session. The main key
must be present exactly once, and unlisted subpaths are hidden atomically.

`Delete` writes a tombstone first. Deleting the main subpath cascades to all
subpaths and hides the session from list, load, and resume.
