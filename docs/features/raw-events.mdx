---
title: "Raw Events"
description: "Opt-in raw Codex event notifications."
---

Raw events are emitted as extension notifications named `_codex/rawEvent`.
They are disabled by default.

Enable them for a session with metadata:

```json
{
  "codex": {
    "rawEvent": {
      "enabled": true
    }
  }
}
```

Embedded Go callers can use:

```go
req := codexacp.NewSessionRequest("/workspace/project",
    codexacp.WithSessionRawEvents(true),
)
```

Each notification includes `sessionId`, monotonic `sequence`, `source`, and an
`event` object. Payloads are capped at 64 KiB; oversized payloads are replaced
with a compact truncation marker.
