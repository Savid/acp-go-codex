Raw Codex events are an opt-in diagnostic/export surface. The typed ACP updates
remain the main host API.

## Capability

The initialize response advertises raw event support under
`agentCapabilities.meta.codex.sdkMessages`:

```json
{
  "scope": "session",
  "method": "_codex/sdkMessage",
  "enabledBy": "_meta.codex.emitRawSDKMessages"
}
```

Raw events are emitted as extension notifications named `_codex/sdkMessage`.

## Enable all raw messages

Set `_meta.codex.emitRawSDKMessages` to `true` on `session/new`,
`session/load`, `session/resume`, or `session/fork`:

```json
{
  "codex": {
    "emitRawSDKMessages": true
  }
}
```

Embedded Go callers can use:

```go
codexacp.WithSessionRawSDKMessages(true)
```

## Enable selected raw messages

Set `_meta.codex.emitRawSDKMessages` to a filter array:

```json
{
  "codex": {
    "emitRawSDKMessages": [
      {"type": "event_msg", "payloadType": "agent_message"},
      {"type": "response_item", "payloadRole": "assistant"}
    ]
  }
}
```

Filters match:

- top-level rollout row `type`;
- optional `payload.type`;
- optional `payload.role`.

## Notification payload

Each `_codex/sdkMessage` notification includes the ACP session ID, Codex method
metadata when known, and the raw JSON payload. The raw bytes are preserved
where possible so hosts can export diagnostics without waiting for typed ACP
fields to cover every Codex rollout detail.

## Restore rule

Filtered raw events are lossy. Do not treat `_codex/sdkMessage` as the durable
restore mechanism unless the host captured every rollout row needed for exact
Codex resume.

For durable restore, prefer [SessionStore](/docs/features/session-store) or the
[`_codex/session/import*`](/docs/reference/session-import) extension methods.
