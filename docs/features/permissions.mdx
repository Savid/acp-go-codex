---
title: "Permissions"
description: "Codex approval and sandbox options."
---

Session metadata can preserve per-session Codex approval and sandbox settings:

```go
codexacp.WithSessionCodexOptions(codexacp.NewCodexOptions(
    codexacp.WithCodexApprovalPolicy("never"),
    codexacp.WithCodexSandboxPolicy("workspace-write"),
))
```

MCP tool trust is configured separately:

```go
codexacp.WithCodexMCPToolApprovalMode("approve")
```

Codex permission requests are bridged to ACP `session/request_permission`.
Elicitation requests are sent only when the client advertised the matching
capability.
