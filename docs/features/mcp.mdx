---
title: "MCP"
description: "Thread-scoped MCP server configuration."
---

The adapter accepts stdio and streamable HTTP MCP servers. Configuration is
thread-scoped and is re-supplied when a logical session resumes on a replacement
app-server. SSE and ACP transports are rejected.

MCP environment variables may not claim Codex home/XDG roots or the adapter's
private `ACP_GO_CODEX_INTERNAL_` namespace.
