---
title: "MCP"
description: "MCP server configuration supported by Codex."
---

`acp-go-codex` accepts stdio and streamable HTTP MCP servers and converts them
to Codex app-server configuration.

```go
req := codexacp.NewSessionRequest("/workspace/project",
    codexacp.WithSessionMCPServers(codexacp.StdioMCPServer(
        "tools",
        "node",
        []string{"server.js"},
        nil,
    )),
    codexacp.WithSessionCodexOptions(codexacp.NewCodexOptions(
        codexacp.WithCodexMCPToolApprovalMode("approve"),
    )),
)
```

`mcpToolApprovalMode` accepts `auto`, `prompt`, or `approve` and applies to all
configured MCP servers for that session.

MCP transports other than stdio and streamable HTTP are rejected with invalid
params.
