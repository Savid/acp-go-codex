---
title: "Models and Config"
description: "Model, mode, thought level, and model config options."
---

Set a default model for new sessions:

```sh
acp-go-codex -model gpt-5.5
```

```go
codexacp.WithDefaultModel("gpt-5.5")
```

Session metadata can set Codex-specific options:

```go
codexacp.WithSessionCodexOptions(codexacp.NewCodexOptions(
    codexacp.WithCodexModel("gpt-5.5"),
    codexacp.WithCodexEffort("high"),
    codexacp.WithCodexServiceTier("flex"),
    codexacp.WithCodexPersonality("pragmatic"),
))
```

ACP config categories are:

| Config | Category |
| --- | --- |
| `model` | `model` |
| `mode` | `mode` |
| `effort` | `thought_level` |
| `serviceTier` | `model_config` |
| `personality` | `model_config` |

Change mode after session start with `session/set_config_option`.
