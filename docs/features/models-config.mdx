---
title: "Models and Config"
description: "Codex model, session option, and configuration controls."
---

Set a default model with `-model` or `WithDefaultModel`. Session metadata can
select model, reasoning effort, service tier, personality, environment, and
extra path directories for that thread.

`WithCodexConfigOverrides` supplies app-server configuration values. Roots
owned by thread configuration are reserved. `WithSeedFiles` writes validated
relative files into the resolved Codex home before a managed tree is prepared
or an ordinary process is launched.
