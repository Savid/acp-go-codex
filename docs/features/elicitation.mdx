---
title: "Elicitation"
description: "Codex request_user_input handling."
---

Codex server requests that require user input are forwarded to ACP elicitation
only when the client advertised the required capability at initialize time.

If the client did not advertise support, the adapter rejects the server request
instead of attempting an unsupported client call.

Raw diagnostics for these requests are available through `_codex/rawEvent` when
the session opts in.
