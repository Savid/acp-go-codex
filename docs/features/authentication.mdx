---
title: "Authentication"
description: "Codex login, external ChatGPT tokens, and logout."
---

Terminal login helpers:

```sh
acp-go-codex login
acp-go-codex login -device-auth
acp-go-codex logout
```

During ACP initialize, terminal auth is advertised only when the client
declares terminal auth support. Agent auth always advertises the stable method
`codex-chatgpt-auth-tokens`.

Embedded token refresh:

```go
agent := codexacp.NewAgent(
    codexacp.WithCodexChatGPTAuthTokenRefresher(func(ctx context.Context) (codexacp.ChatGPTAuthTokens, error) {
        return codexacp.ChatGPTAuthTokens{AccessToken: "token"}, nil
    }),
)
```

ACP logout is disabled unless explicitly enabled with
`WithCodexAllowAccountLogout(true)` or `-codex-allow-account-logout`.
