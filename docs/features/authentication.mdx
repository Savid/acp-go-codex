---
title: "Authentication"
description: "Codex account and provider authentication surfaces."
---

ACP account reads and shared app-server authentication use the Agent-owned
runtime. Terminal `login` and `logout` require an explicit canonical Codex home
as their mutation-consent boundary.

Embedded managed hosts use the same `HostAuthority` for version probes, account
commands, browser shims, and app-server launches. Each helper uses host stdio and
has no direct-process fallback.

Provider authentication remains gated by `WithProviderAuthRoot` and
`WithProviderAuthDirectHome`; the ledger contains coordination metadata, not
credential values.
