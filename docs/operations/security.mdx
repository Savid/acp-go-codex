---
title: "Security"
description: "Security boundaries for acp-go-codex."
---

`-home` and `WithHome` choose the Codex home used by launched Codex processes.
Use an adapter-owned directory when enabling logout.

ACP logout is disabled by default. Enable it only with
`-codex-allow-account-logout` or `WithCodexAllowAccountLogout(true)`.

The adapter accepts stdio and streamable HTTP MCP servers. Other MCP transports
are rejected.

Raw events can contain Codex rollout JSON. Enable `_codex/rawEvent` only when
the host is prepared to receive and protect that data.
