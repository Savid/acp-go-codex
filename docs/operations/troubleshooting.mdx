---
title: "Troubleshooting"
description: "Common runtime and authority failures."
---

| Symptom | Resolution |
| --- | --- |
| `host authority unavailable` | Supply a non-nil authority with a valid native environment and complete process stdio. |
| `native containment incomplete` | The managed runtime did not reach terminal proof or a prepared tree could not be reclaimed. Fix the host authority before retrying admission. |
| `native tree has live lease processes` | Wait for or revoke the native lease before reclaiming that tree. |
| Managed executable must be staged and pinned | Configure a host-pinnable selector; do not point managed mode at a session-created package copy. |
| Codex CLI is too old | Upgrade Codex or configure another selector. Version `0.144.1` or newer is required. |

Session cancellation errors concern only the target thread's protocol cleanup;
they do not cause shared-runtime revocation.
