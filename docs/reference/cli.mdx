---
title: "CLI"
description: "Standalone acp-go-codex command flags and account commands."
---

```sh
acp-go-codex [flags]
acp-go-codex login -home /absolute/codex-home
acp-go-codex logout -home /absolute/codex-home
```

The main command serves ACP JSON-RPC on stdin/stdout and launches Codex as the
current user. Common flags select the Codex executable (`-path`), Codex home
(`-home`), scratch parent (`-scratch-dir`), default model (`-model`), and
OpenTelemetry settings. Run `acp-go-codex -help` for the current complete list.
Provider-auth hosts configure the durable ledger with `-provider-auth-root` and
may explicitly permit direct home writes with `-provider-auth-direct-home`.
Use `-debug` for diagnostic logging and `-version` to print the adapter version.

Managed execution is an embedding API: a Go host passes `WithHostAuthority`.
The standalone CLI has no authority configuration flags.
