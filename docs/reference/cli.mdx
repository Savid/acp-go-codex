---
title: "CLI"
description: "acp-go-codex command-line reference."
---

```sh
acp-go-codex [flags]
```

| Flag | Default | Description |
| --- | --- | --- |
| `-path` | `codex` on `PATH` | Codex CLI executable path. |
| `-home` | unset | Codex home directory passed as `CODEX_HOME`. |
| `-model` | unset | Default model preference. |
| `-debug` | `false` | Write adapter debug logs to stderr. |
| `-version` | `false` | Print adapter version and exit. |
| `-codex-allow-account-logout` | `false` | Permit ACP logout to call Codex logout. |

Login helpers:

```sh
acp-go-codex login [-path PATH] [-home DIR] [-device-auth]
acp-go-codex logout [-path PATH] [-home DIR]
```
