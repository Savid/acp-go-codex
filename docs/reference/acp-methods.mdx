The adapter routes the standard ACP method set and adds two namespaced
`_codex/*` extensions. This page lists each method and its behavior.

## Supported methods

| Method | Status |
| --- | --- |
| `initialize` | implemented |
| `session/new` | implemented |
| `session/prompt` | implemented |
| `session/cancel` | implemented |
| `session/close` | implemented |
| `session/list` | implemented |
| `session/load` | implemented |
| `session/resume` | implemented |
| `session/delete` | implemented |
| `session/set_config_option` | implemented |

## Extensions and unsupported methods

Codex extension methods live under the `_codex/*` namespace:

| Method | Status |
| --- | --- |
| `_codex/session/fork` | implemented through `HandleExtensionMethod` |
| `_codex/rawEvent` | notification only |

Unsupported or removed methods return method-not-found uniformly. `session/fork`
and `session/set_mode` are intentionally not routed.

## Slash commands

acp-go-codex advertises no ACP slash commands. `/review`, `/plan`, `/compact`,
and other slash-prefixed text remains ordinary `session/prompt` text and reaches
Codex as `turn/start` input.

Skills surfaces (`skills/list`, `$skill`, `type:"skill"` items) are not commands
and are not projected as `AvailableCommand` entries.
