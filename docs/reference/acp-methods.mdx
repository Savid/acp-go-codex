---
title: ACP Methods
description: Agent methods implemented by the local dispatcher.
---

The method surface is identical in standalone CLI and embedded Go. The only
difference is whether the ACP connection reaches the agent through process
stdio or through streams passed to `codexacp.Serve`.

## Stable methods

| Method | Status |
| --- | --- |
| `initialize` | implemented |
| `authenticate` | implemented for external ChatGPT tokens; terminal auth is advertised as a command auth method |
| `session/new` | implemented |
| `session/prompt` | implemented |
| `session/cancel` | implemented |
| `session/close` | implemented |
| `session/list` | implemented |
| `session/load` | implemented |
| `session/resume` | implemented |
| `session/set_mode` | implemented |
| `session/set_config_option` | implemented |

## Unstable methods

| Method | Status |
| --- | --- |
| `session/fork` | implemented |
| `session/set_model` | implemented for SDK compatibility; prefer `session/set_config_option` with `model` |
| `logout` | implemented only when `WithAllowAccountLogout(true)` is configured |
| `mcp/message` | implemented for ACP-transport MCP |

The adapter intentionally does not implement provider management APIs, goals,
document/NES APIs, plugin/marketplace mutation, realtime thread APIs, or
external-agent mutation.

## Codex extension methods

| Method | Purpose |
| --- | --- |
| `_codex/session/import` | One-shot import and commit of Codex rollout JSONL entries. |
| `_codex/session/importChunk` | Append a chunk to a pending import. |
| `_codex/session/commitImport` | Commit a pending import into the session store. |
| `_codex/session/abortImport` | Drop a pending import. |
| `_codex/turn/steer` | Steer the active Codex turn with Codex input or ACP prompt content. |
| `_codex/thread/compact` | Call Codex `thread/compact/start` for a session thread. |
| `_codex/review/start` | Call Codex `review/start` for a session thread. |
| `_codex/thread/read` | Return Codex `thread/read` history for a session thread. |
| `_codex/thread/turns/list` | Return Codex `thread/turns/list` for a session thread. |
| `_codex/collaborationMode/list` | Return Codex collaboration modes. |
| `_codex/mcpServerStatus/list` | Return Codex MCP server status. |

Unsupported extension methods return method-not-found errors.

## Extension notifications

| Method | Purpose |
| --- | --- |
| `_codex/sdkMessage` | Emits selected raw Codex rollout rows. |
