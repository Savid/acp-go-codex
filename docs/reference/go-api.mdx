---
title: "Go API"
description: "Public Go API for embedding acp-go-codex."
---

`Serve` runs the ACP connection on caller-owned streams. `NewAgent` builds an
Agent for a host that owns connection setup.

```go
agent := codexacp.NewAgent(
	codexacp.WithExecutablePath("codex"),
	codexacp.WithHome("/srv/codex"),
	codexacp.WithHostAuthority(authority),
)
```

`HostAuthority` provides `NativeEnvironment`, `PrepareNativeTree`,
`ReclaimNativeTree`, and `StartNative`. `StartNative` receives a `NativeRequest`
and returns a `NativeProcess` with host-provided stdio plus `Wait` and `Revoke`.
The stable errors are `ErrHostAuthorityUnavailable`,
`ErrContainmentIncomplete`, and `ErrNativeTreeBusy`.

Omit `WithHostAuthority` for ordinary same-user execution. Other public options
configure the executable selector, Codex home, scratch parent, model, session
store, concurrency and image limits, provider authentication, telemetry, seed
files, and Codex configuration overrides. See
[pkg.go.dev](https://pkg.go.dev/github.com/savid/acp-go-codex) for signatures.
