## Serve and embed

`Serve` runs the ACP agent on caller-owned streams; `NewAgent` builds the agent
for hosts that drive the ACP connection themselves. Both take the process
options below.

```go
err := codexacp.Serve(ctx, stdin, stdout,
	codexacp.WithExecutablePath("/usr/local/bin/codex"),
	codexacp.WithHome("/tmp/codex-home"),
	codexacp.WithDefaultModel("gpt-5.5"),
	codexacp.WithLogger(logger),
)
```

This omission is ordinary current-identity execution. Add
`WithProcessIsolation(...)` only for the explicit trusted-root Linux policy.

`Serve` closes the agent before it returns. If shutdown fails, that close error
takes precedence over EOF or context cancellation. In particular,
`errors.Is(err, codexacp.ErrProcessContainmentIncomplete)` means the selected
native containment boundary did not complete; an embedding host must keep that
runtime and its resources quarantined. Absence of the sentinel does not prove
escaped descendants are absent on Darwin.

## Agent options

| Option | Purpose |
| --- | --- |
| `WithExecutablePath(path)` | Codex CLI executable path (defaults to `codex` on `PATH`). |
| `WithProcessIsolation(policy)` | Explicit hardening with a nonzero target UID/GID and complete replacement environment. All privilege, ownership, authority, and cleanup proofs remain fail-closed. Omit it for ordinary current-identity execution. |
| `WithHome(path)` | `CODEX_HOME` for launched Codex processes. Standalone isolation defaults it to `StandaloneStateRoot` and rejects any different explicit path. |
| `WithScratchDir(dir)` | Parent directory for all ephemeral on-disk materialization; empty means the system temp directory. Created `0700` when missing. |
| `WithDefaultModel(model)` | Default model preference for new sessions. |
| `WithEnv(env)` | Ordinary environment overrides. With explicit isolation they overlay `ProcessIsolation.BaseEnvironment`; otherwise they overlay the environment captured when the agent was constructed. Managed homes/XDG roots retain adapter precedence, and adapter-internal names are scrubbed or rejected. |
| `WithLogger(logger)` | `*slog.Logger` for structured adapter diagnostics. |
| `WithSessionStore(store)` | Replace the default in-memory lifecycle authority with a durable Codex rollout JSONL store. |
| `WithSessionStoreLoadTimeout(d)` | Deadline for store-backed load/list (default `10s`; ≤ 0 uses the default). |
| `WithConcurrencyLimits(limits)` | Bounds active sessions, prompts, and client calls. |
| `WithTurnTimeout(d)` | Bounds a single `session/prompt` turn; `0` disables the deadline. |
| `WithImageLimits(limits)` | Bounds decoded prompt and emitted image bytes. Each field defaults to 6 MiB; an explicit zero disables that policy bound. |
| `WithInputHandoffRoot(dir)` | Enable the local handoff prompt transport and confine it to `dir`, a read-only root. Requires an absolute path. Unset, the handoff form is rejected. |
| `WithProviderAuthRoot(path)` | Absolute durable directory holding the values-free provider-auth ledger. Unset — or set to a path that cannot be prepared — leaves every `_codex/auth/*` method unadvertised. |
| `WithProviderAuthDirectHome(path)` | Exact `CODEX_HOME` the host consents to the `credential` and `disconnect` legs touching. Both legs are advertised only while this equals the resolved `WithHome`. |
| `WithRuntimeResourceHooks(hooks)` | Exact-lifetime host accounting for native roots and adapter scratch roots. |
| `WithDarwinBestEffortContainment()` | Explicitly accept Darwin's direct-child plus captured-process-group boundary. Rejected off Darwin and mutually exclusive with `WithProcessIsolation`; without it Darwin uses ordinary current-identity execution and reports `shared_identity`. |
| `WithSeedFiles(files)` | Write relative-path files into `CODEX_HOME` before each Codex process launches. Requires an explicit `WithHome`. |
| `WithCodexConfigOverrides(overrides)` | TOML config overrides passed to `codex app-server` as `-c key=value`; dotted keys set nested config, nothing is written to disk, and the session-scoped `mcp_servers` and thread-owned `shell_environment_policy` keyspaces are rejected whole. |
| `WithCodexChatGPTAuthTokenRefresher(fn)` | External ChatGPT token refresh callback. |
| `WithCodexAllowAccountLogout(enabled)` | Permit ACP logout to mutate adapter-owned Codex auth. Enabling it requires an explicit `WithHome` consent boundary. |
| `WithAgentName(name)` | Protocol identifier advertised at initialize. |
| `WithAgentTitle(title)` | Human-readable agent name advertised at initialize. |
| `WithAgentVersion(version)` | Agent version advertised at initialize. |
| `WithTracerProvider` / `WithMeterProvider` / `WithTextMapPropagator` | Caller-owned OpenTelemetry providers (see [Observability](/docs/operations/observability)). |

`ProcessIsolation.IdentityLock` and `ProcessIsolation.AuthorityDomain`
optionally accept opaque host capabilities with `Duplicate() (*os.File, error)`
for the already-held canonical UID lock and shared `domain.lock` lease. Each
capability keeps ownership of its original descriptor; caller-owned duplicates
reach only the trusted supervisor, which validates the named inodes, held locks,
and strict matching domain record and protects them with checked `FD_CLOEXEC`.
Set both fields together for
host-borrowed authority or leave both nil for standalone domain, permanent
provider-owner binding, retained `ACTIVE`, and UID-lock acquisition. A
mixed nil/non-nil pair fails closed. Borrowed authority rejects owned UIDs. Native
processes receive neither capability nor descriptor.

For an explicit policy, `ProcessIsolation.StandaloneOwnerID` and
`ProcessIsolation.StandaloneStateRoot` are required when both capabilities
are nil and forbidden when both are set. The owner ID is the nonsecret
case-sensitive deployment identity: 1--256 canonical ASCII bytes beginning
alphanumeric, followed only by alphanumerics or `._:@/-`. The state root is
the existing dedicated durable provider home, neither `/` nor equal to or
beneath `/var/lib/acp-go/agent-identities`, expressed as a clean absolute UTF-8 path of
at most 4096 bytes with no control character. Linux resolves it from `/`
without symlinks or magic links, requires protected root-owned ancestry and an
exact configured UID:GID mode-`0700` final directory, and binds the exact
path, device, and inode. The protected path and metadata are revalidated
immediately before `ACTIVE` publication and native launch. Standalone claims
are permanent; changing either value does not migrate authority and fails
closed. Standalone `WithHome` defaults to this exact state root and any
different explicit home fails construction validation.

`WithSeedFiles` writes config files into the resolved `CODEX_HOME` before each
Codex process launches, so Codex reads them as its own config. Paths are
relative and confined to `CODEX_HOME`; absolute paths, `..` escapes, and empty
keys fail closed at session start. `WithHome` must be set explicitly — seeding
never writes into the operator's default `~/.codex`. A seeded
`CODEX_HOME/config.toml` feeds the same app-server keyspace as
`WithCodexConfigOverrides`, so it carries the same reservation: a file
declaring the `mcp_servers` or `shell_environment_policy` root in any TOML
spelling fails closed before any file is written. Writes are tracked in a
`.seed-manifest.json` ownership manifest: a managed file is overwritten in
place (prior bytes kept in a `<relpath>.seed.bak` sidecar when content changes),
while an existing file the adapter does not own fails closed and is never
clobbered. Keep secrets in `WithEnv` and reference them from seeded files by
Codex `env_key` indirection.

`WithCodexConfigOverrides` reaches a LiteLLM gateway with no file on disk: dotted
keys set nested config, string values are TOML-quoted automatically, and nothing
is written to disk, so `WithHome` can point at the operator's real Codex dir and
its `config.toml` and auth stay untouched. `codex app-server` has no config-file
overlay flag, so this is the config mechanism for the app-server.

```go
err := codexacp.Serve(ctx, stdin, stdout,
	codexacp.WithEnv(map[string]string{"LITELLM_API_KEY": "sk-..."}),
	codexacp.WithCodexConfigOverrides(map[string]any{
		"model":                            "gpt-5.5",
		"model_provider":                   "litellm",
		"model_providers.litellm.name":     "LiteLLM",
		"model_providers.litellm.base_url": "https://litellm.example/v1",
		"model_providers.litellm.env_key":  "LITELLM_API_KEY",
		"model_providers.litellm.wire_api": "responses",
	}),
)
```

| Helper | Purpose |
| --- | --- |
| `NewSessionRequest` | Build `session/new`. |
| `LoadSessionRequest` | Build `session/load`. |

| `RateLimitsResponse` | Decode the `_codex/rateLimits` reply (`Windows`, `PlanType`). |
| `RateLimitWindow` | One rate-limit window (`ID`, `UsedPercent`, `ResetsAt`). |
| `StdioMCPServer` | Construct a stdio MCP server; adapter-reserved process-management and Darwin correlation env names are rejected case-insensitively. |
| `HTTPMCPServer` | Construct a streamable-HTTP MCP server. |
| `WithSessionMCPServers` | Attach MCP servers to a session. |
| `WithSessionRawEvents` | Enable `_codex/rawEvent`. |
| `WithSessionOutputSchema` | Configure structured output. |
| `WithSessionCodexOptions` | Merge `_meta.codex.options`. |
| `WithCodexEnv` | Set cloned environment values on this session's Codex thread through `shell_environment_policy.set`. A raw `PATH` and adapter-reserved process-management or managed-home names fail closed. |
| `WithCodexExtraPathDirs` | Set cloned, ordered absolute directories that prefix the app-server's native `PATH` for this session's Codex thread. Order and duplicates are preserved. |
| `PromptRequest` / `TextPromptRequest` | Build a prompt with mandatory route version and a nonblank turn nonce of at most 4096 bytes; invalid input omits route metadata so the agent rejects it. |
| `CancelRequest` | Build an active-turn cancellation with the same bounded route; invalid input likewise fails closed. |

`Agent.ContainmentMode()` returns `authoritative`, `best_effort`,
`shared_identity`, or
`unavailable`. Omitted isolation reports `shared_identity` on every platform
where native launch works, for root and nonroot callers alike. It carries no
credential-separation, provider-descendant inventory, or whole-tree quiescence
claim. Explicit isolation is distinct, trusted-root Linux only, and reports
`authoritative`; any validation, authority, or launch failure is terminal and
never retries ordinary mode. Opted-in Darwin is `best_effort`; it reaps the
direct child and drains the captured original process group, but cannot contain
`setsid` escapees or eliminate numeric-PGID-reuse collateral-signalling risk.
Windows supports ordinary runtimes and logout but refuses browser-based login.

`RuntimeResourceHooks` exposes `AcquireNativeRoot`, `ReserveScratchRoot`,
`ObserveProcess`, `ObserveProcessSnapshot`, `ObserveStartupStage`, and
`ObserveContainment`.
Admission callbacks receive one of `runtime`, `session`, `prompt`, or
`discovery`; rejection is propagated fail closed. A successful hook must
return a release function. The adapter releases a native-root reservation only
after the full client process has exited, and a scratch reservation only after
its root has been deleted. On supervised boundaries Codex reports the two actual
home-lock supervisors after readiness and removes them when their waiter proves
exit; direct ordinary backends do not fabricate supervisor counts. Absolute
descendant snapshots are emitted only for authoritative explicit isolation,
never for ordinary or best-effort modes. Startup stages are `spawn`,
`readiness`, `configuration`, and native `session` creation. Nil callbacks
select standalone, adapter-owned unbounded accounting.
Ordinary and best-effort modes emit the containment selection but no
provider-descendant snapshot, including no terminal zero. If cleanup returns
`ErrProcessContainmentIncomplete`, hosts must retain the exact scratch and
native-root reservations as quarantined resources.

`ImageLimits` has four decoded-byte fields:

```go
type ImageLimits struct {
	MaxInputBytesPerImage     int64
	MaxInputBytesPerPrompt    int64
	MaxOutputBytesPerImage    int64
	MaxOutputBytesPerToolCall int64
}
```

Negative values make initialization fail with invalid params. The prompt total
is across every image in one request. The tool-call total is across the
complete image content snapshot for one native image tool call.

## Provider-auth types

The `_codex/auth/credential` leg returns the harvested login through these
exported shapes. They are the only public Go types a brokered credential
crosses in, and they are the same shapes the wire carries.

```go
type ProviderCredentialType string

const ProviderCredentialOAuth ProviderCredentialType = "oauth"

type ProviderOAuthCredential struct {
	Refresh         string `json:"refresh"`
	Access          string `json:"access"`
	AccessExpiresAt int64  `json:"accessExpiresAt"`
	AccountID       string `json:"accountId,omitempty"`
	EnterpriseURL   string `json:"enterpriseUrl,omitempty"`
}

type ProviderCredential struct {
	Type  ProviderCredentialType
	OAuth *ProviderOAuthCredential
}
```

`ProviderCredential` marshals to one flat object whose `type` selects the
variant. Decoding is strict: an unknown field, a duplicate field, an empty
required string, and any variant this adapter does not emit are rejected rather
than partially decoded. `AccessExpiresAt` is Unix epoch milliseconds.
